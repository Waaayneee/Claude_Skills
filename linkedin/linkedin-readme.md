# LinkedIn Caption Writer Readme

## 1. What It Does

Writes a reflective, personal-growth style LinkedIn caption based on an uploaded photo. Output includes a hook line, context on the event or achievement, a behind-the-scenes note, a lesson-learned section, optional thanks, a closing line, and relevant hashtags.

## 2. How To Invoke

| Method | Example |
|---|---|
| Slash command with photo | Attach a photo and type "/linkedin". |
| Natural phrasing | Attach a photo and say "write a linkedin caption for this". |
| No photo attached | The skill will ask for a photo to be uploaded before writing anything. |

## 3. Notes

- Unknown details such as event names, dates, or headcounts are marked with a placeholder like [event name] rather than guessed.
- Revisions such as shorter, more casual, or different hashtags can be requested without re-uploading the photo.
- If multiple photos are attached, it will ask which one to use unless they are clearly part of the same event.
- Timing phrasing adjusts automatically based on how recent the photo is, from fresh, to recent, to a throwback framing.
