# Humanizer Readme

## 1. What It Does

Rewrites text to remove signs of AI-generated writing and adds natural personality and voice. It targets patterns such as inflated significance, promotional language, vague attribution, em dash overuse, rule-of-three padding, filler phrases, excessive hedging, and more. It can optionally match a writing sample you provide.

## 2. How To Invoke

| Method | Example |
|---|---|
| "/humanizer" | Use this to humanize the text in the chatbox or the prompt output |
| Trigger word | Use the word "humanize" or "/humanizer" together with the text to be edited. |
| Voice matching | Paste a sample of your own writing alongside the request so the rewrite matches your style. |
| No trigger, direct ask | Ask to "make this sound less AI" or "edit this to sound natural". |

## 3. Output Format

1. Draft rewrite
2. A short self-audit of remaining AI tells
3. Final revised version
4. A brief summary of changes made, if helpful

## 4. Notes

If no writing sample is given, the skill falls back to a natural, varied, opinionated default voice. If a sample is given, sentence length, word choice, punctuation habits, and paragraph structure are matched to it instead.
